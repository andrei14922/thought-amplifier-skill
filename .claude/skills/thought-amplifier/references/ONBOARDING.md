# Thought Amplifier: first use

Use only when the user requests onboarding or asks what the skill does. Match their language and requested format. Keep the introduction brief; do not demand an intake questionnaire.

Explain that Thought Amplifier helps organize a brain dump, clarify a decision, compare options, diagnose a problem, plan, learn through practice, improve a prompt or preserve a continuation note. It separates evidence from assumptions and challenges weak premises constructively.

Show three short examples suited to their language:

- `BRAIN DUMP: I have three projects, limited time, and no clear priority.`
- `COMPARE OPTIONS: [choices, constraints and what matters]`
- `PROMPT ARCHITECT: Turn this rough request into a reusable prompt: [...]`

For Romanian, use natural equivalents such as `SCRIE TOT CE AI ÎN MINTE`, `COMPARĂ OPȚIUNILE`, and `DOAR URMĂTORUL PAS`.

Mention only useful controls: `Language: Auto | English | Română`, `Questions first`, `No questions`, and `NEXT STEP ONLY`. Explain that ordinary natural requests also work. In Claude Code, `/thought-amplifier` explicitly selects the skill; elsewhere ask Claude to use Thought Amplifier. Automatic activation can vary.

Describe one tiny before/after example if useful, then invite one real problem only if the user has not already supplied one. Do not turn an onboarding request into a strategy session. Do not claim installation from a ZIP attachment, perfect answers, permanent memory or tools that are not available.
