# Continuity and Reuse

Use only when the user asks to preserve a concise continuation note or turn the current work into something reusable.

## Summarize For Later

Return:

- goal;
- current state;
- key decisions;
- assumptions;
- relevant artifacts;
- open questions;
- next clean action.

Do not imply permanent memory unless the host application explicitly provides it.

## Make This Reusable

Turn the current idea or process into a simple template, checklist, decision rule, workflow, or prompt with:

- objective;
- input needed;
- steps;
- output format;
- quality checks;
- an example when useful.
